# Expressar opinião e argumentar

Para participar de una conversación o un debate de nivel intermedio, necesitás poder dar tu opinión, mostrar acuerdo o desacuerdo y justificar lo que decís con razones. Esta semana vamos a aprender las expresiones clave para eso y vamos a terminar escribiendo un comentario de opinión breve.

## Día 1 — Dar tu opinión: acho que, acredito que

| Expresión | Registro | Ejemplo |
|---|---|---|
| acho que | neutro, muy usado | *Acho que esse filme é bom.* |
| acredito que | algo más formal | *Acredito que isso vai mudar.* |
| na minha opinião | al inicio, con coma | *Na minha opinião, ele está errado.* |

- *Eu acho que isso é verdade.* → Creo que eso es verdad.
- *Na minha opinião, deveríamos trabalhar menos horas.* → En mi opinión, deberíamos trabajar menos horas.

**Ojo:** con "acho que" afirmativo se usa indicativo, no subjuntivo, aunque en español a veces usemos subjuntivo con "no creo que".

## Día 2 — Acuerdo y desacuerdo

- Acuerdo: *Concordo totalmente com você.* / *Você tem razão.*
- Desacuerdo: *Discordo.* / *Não concordo com essa ideia.*
- Para discrepar con tacto: *Eu entendo seu ponto, mas...*

**Ojo:** "concordar" siempre lleva "com": *concordo com você*, no *concordo você*.

## Día 3 — Dar razones: porque, pois

| Conector | Uso |
|---|---|
| porque | causal, de uso general |
| pois | causal, más formal/escrito |
| pois é | expresión fija: "así es" |

- *Precisamos agir rápido, pois o problema está crescendo.* → Necesitamos actuar rápido, porque el problema está creciendo.

**Ojo:** "pois" no funciona como el "pues" dubitativo del español al inicio de una frase; para eso se usa "bom" o "bem".

## Día 4 — Matizar una opinión

| Expresión | Significado |
|---|---|
| de certa forma | de cierta forma |
| por um lado... por outro lado | por un lado... por otro lado |
| talvez | tal vez |
| não tenho certeza, mas | no estoy seguro, pero |

- *Por um lado, o projeto é interessante, por outro, é muito caro.* → Por un lado, el proyecto es interesante, por otro, es muy caro.

**Ojo:** después de "talvez" se prefiere el subjuntivo: *talvez seja melhor*, no *talvez é melhor*.

## Día 5 — Escribir un comentario de opinión breve

La estructura típica es: opinión → razón → matiz → cierre.

- *Na minha opinião, as redes sociais têm pontos positivos e negativos.*
- *Acho que elas ajudam a nos conectar, porque facilitam a comunicação.*
- *No final das contas, cada pessoa deve decidir o que é melhor para si.*

## En pocas palabras

- **Opinión:** *acho que*, *acredito que*, *na minha opinião*.
- **Acuerdo/desacuerdo:** *concordo com*, *tem razão*, *discordo*.
- **Razones:** *porque*, *pois* (más formal).
- **Matices:** *de certa forma*, *por um lado... por outro lado*, *talvez*.
- **Cierre de un comentario:** *de qualquer forma*, *em resumo*, *no final das contas*.
